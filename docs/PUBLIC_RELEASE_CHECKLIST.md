# Public release checklist

- [ ] Every file is original or licensed for public release.
- [ ] No source PDF, extracted text, internal audit or private source material is included.
- [ ] No secrets, live connector URLs, account IDs or personal records are included.
- [ ] Git history contains no previously committed secret or private material.
- [ ] Licence scope is clear and limited to this folder.
- [ ] Clone and validator commands work from a clean directory.
- [ ] Every README link resolves.
- [ ] Synthetic examples are clearly labelled.
- [ ] Supported hosts and test coverage are described honestly.
- [ ] Owner, issue triage and security reporting routes are assigned.
- [ ] Release archive and checksums are generated and verified.

Do not publish until all critical items pass and the maintainer records approval.
