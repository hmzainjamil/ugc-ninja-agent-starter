# Brand and usage guide

## Product identity

**Name:** UGC Ninja Agent Starter  
**Descriptor:** Human-governed AI starter for evidence-led UGC and creator workflows  
**Primary message:** Make creator-content operations easier to inspect, review and improve.

## Brand voice

Use direct, specific, evidence-led language. Explain the workflow and its limits. Prefer verbs such as verify, brief, review, approve, publish and learn. Avoid claims of autonomous growth, guaranteed compliance, guaranteed conversions or viral performance.

## Visual system

| Token | Value | Intended use |
|---|---|---|
| Ink navy | `#101B2B` | Primary background and headings |
| Electric mint | `#72E0B1` | Primary accent and action |
| Signal violet | `#8B7CFF` | Secondary accent |
| Paper | `#F5F7FA` | Light surface |
| Steel | `#64748B` | Secondary text |
| Alert coral | `#F47B70` | Risk and stop states |

Use the logo SVG at its natural ratio. Keep enough clear space around it. Do not redraw it to imitate another brand, imply platform endorsement or use the mark as a guarantee of product quality. MIT applies to the code and documentation, not to trademark rights.

## Repository presentation

Use the included 1280 × 640 social preview for repository or launch-page artwork. The preview file is an editable SVG and PNG export. When changing the title or feature counts, update both formats and rerun the image review.

## Writing examples

**Use:** Three skills, one reviewable workflow and an explicit human approval boundary.  
**Avoid:** Fully autonomous viral marketing that guarantees results.
