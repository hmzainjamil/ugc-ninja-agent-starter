# Contributing

Contributions should improve clarity, correctness, usability or safety.

1. Open an issue for material changes and state the intended user benefit.
2. Use original content or material whose licence permits redistribution.
3. Use synthetic data in examples and tests.
4. Do not include credentials, personal data, private creator information, contracts or payment details.
5. Explain affected skills and workflow steps.
6. Run `python3 scripts/validate_showcase.py` before submitting.
7. Explain any untested host-specific behaviour.

A contribution does not authorise public posting, creator outreach, payment or other external action.
