# Support

This repository is a community-facing starter, not a hosted application, consultancy engagement or managed service. No uptime commitment or response-time guarantee is offered.

## Before opening an issue

1. Read the README and governed-agent basics.
2. Confirm the commit or release version.
3. Run `python3 scripts/validate_showcase.py`.
4. Search existing issues for the same behaviour.
5. Provide a minimal reproduction with synthetic data.

## Supported request types

- Reproducible defects in files included in this repository.
- Documentation corrections and clearer examples.
- Compatibility reports that state the exact host, version and operating system.
- Focused feature proposals with a concrete user problem.

Questions about third-party agent hosts, platform eligibility, legal interpretation, campaign results and individual account configuration must be handled by the relevant provider or qualified specialist.
