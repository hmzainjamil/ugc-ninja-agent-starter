# Security policy

## Scope

This policy covers the public UGC Ninja Agent Starter repository. It is a small documentation and skill example, not a hosted application or service.

## Report a concern

Do not publish credentials, private account details, personal data, creator records or exploit instructions in a public issue. Use GitHub's private vulnerability reporting feature if enabled for this repository. If it is not enabled, contact the maintainer through the public GitHub profile and request a private reporting route.

Include the affected path and version, impact, reproduction conditions and a safe proof of concept. Do not include live secrets or real customer or creator data.

## Response and remediation

The maintainer will assess scope, reproducibility, severity and affected versions. No response time or service-level agreement is promised. A fixed version or mitigation will be documented when a change is available.

## Safe use

- Keep credentials in an approved secret manager.
- Use synthetic data in issues, screenshots and tests.
- Do not give an agent broader permissions than the task requires.
- Keep external actions disabled until exact approvals and verification steps exist.
